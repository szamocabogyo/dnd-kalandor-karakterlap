# Kiadási ellenőrzőlista

- [ ] A `VERSION`, `version.json` és a Git tag verziója egyezik.
- [ ] A `CHANGELOG.md` Kiadatlan része átkerült az új verzió alá.
- [ ] A karakterlap személyes vagy próbaadatok nélkül kerül kiadásra.
- [ ] Készült biztonsági másolat a kiadás előtti HTML-fájlról.
- [ ] Az exportált karakter visszaimportálható az új verzióba.
- [ ] A mobil és asztali nézet fő folyamatai működnek.
- [ ] A SHA-256 ellenőrzőösszeg elkészült.
- [ ] A licenc- és szabályforrás-megjelölések rendben vannak.
- [ ] A GitHub Release tartalmazza az HTML-fájlt, a változásnaplót és az ellenőrzőösszeget.
